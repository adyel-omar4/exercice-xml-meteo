# exercice-xml-meteo
Exercice XML - DTD, XSD, XSLT, HTML et SVG
## Description
Ce projet consiste à manipuler les technologies XML à travers un exemple de gestion des températures météorologiques de différentes villes marocaines.

## Technologies utilisées
- XML : Structuration des données météorologiques.
- DTD : Définition de la structure du document XML.
- XSD : Validation et définition des types de données.
- XSLT : Transformation du document XML.
- HTML : Présentation des données sous forme de tableaux.
- SVG : Représentation graphique des températures sous forme d'un histogramme animé.

## Contenu du projet
- `meteo.xml` : Document XML contenant les températures.
- `meteo.dtd` : Définition de la structure XML.
- `meteo.xsd` : Schéma de validation XML.
- `meteo-html.xsl` : Transformation XML vers HTML.
- `meteo-svg.xsl` : Transformation XML vers SVG animé.

## Objectif
Mettre en pratique les concepts de structuration, validation et transformation des documents XML.
